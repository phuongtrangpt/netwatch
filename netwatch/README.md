# NetWatch Local

Giám sát router MikroTik RB5009/E50UG và thiết bị mạng. Sơ đồ kéo thả, switch ảo,
neo và đường dây tùy chỉnh, ghim thiết bị, tên gợi nhớ, nhiều dự án DHCP/PPPoE.

Dữ liệu lưu riêng trong `/data`. Không cần Docker host shell hoặc tắt Protection mode.
Chọn **Documentation** để xem cách cấu hình.
